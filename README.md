# TripMind — AI Travel Planner

TripMind is an AI-powered travel planning application designed to simplify the process of exploring destinations and organizing trips. It brings itinerary planning, route visualization, and an interactive globe experience together in a single interface.

The project focuses on making travel planning more intuitive through a combination of modern web technologies and interactive design.

## Features

- **Interactive Globe:** Explore destinations through an immersive globe interface.
- **Route Visualization:** View travel routes and stops on a map.
- **Trip Planning:** Organize travel plans through a guided, step-by-step workflow.
- **Itinerary Timeline:** Present planned activities and schedules in a structured timeline.
- **Modern User Interface:** A clean, interactive interface designed for an engaging planning experience.

## Technology Stack

- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS
- **Backend:** Node.js and Express
- **Routing:** Wouter
- **Package Manager:** pnpm

## Getting Started

### Prerequisites

Ensure that the following tools are installed:

- Node.js
- pnpm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/kalpitasingh/ai-travel-planner.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ai-travel-planner
   ```

3. Install the dependencies:

   ```bash
   pnpm install
   ```

4. Start the development server:

   ```bash
   pnpm dev
   ```

5. Open the local URL provided in the terminal to access the application.
